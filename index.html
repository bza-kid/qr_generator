Quick Transfer Tools

QR-based browser connection and text/link QR-code generation.

QR generation and WebRTC connection information are processed inside the browser. The selected file is not uploaded to GitHub.

Send a File

  1. Select a file below 100 MB.
  2. Create and show the Offer QR to the receiver.
  3. Scan the Answer QR shown by the receiver.
  4. Wait until both devices show Connected.

Current test limit: 100 MB, equal to 100,000,000 bytes. The selected file will not be transferred in this stage.
